# S19 · 20万 GitHub Actions 模拟仓

S19 选股与模拟执行分开：题材强度、连板高度、龙头/二龙头排序和承接过滤负责选股；新鲜行情及买卖盘口负责判断能否模拟成交。不是逐笔回测或真实交易系统。

## 运行规则

- 初始现金 200,000 元，默认每笔约 1/3 初始资金，最多 3 个仓位。
- 信号监控北京时间 09:15–10:57，买入只在连续交易时段且 09:30 以后。
- 模拟仓午后继续检查卖出，15:00–15:01 记录收盘附近估值；09:30–11:30、13:00–14:57 允许模拟成交，集合竞价不虚构成交。
- 持有 5 个交易日或触发 -6% 止损；遵守 T+1。交易日来自 XSHG 日历，超出已知范围时明确失败。
- 买卖使用当天最多 60 秒旧的腾讯行情，校验股票代码、涨跌停价、买卖一档和数量。封涨停不买、封跌停不卖；盘口不足整笔成交量时记录未成交。
- 买卖均应用 5bp 滑点，按不利方向取整到分。单边佣金 3bp；卖出税费默认 5bp，可在 `config.json` 修改。未模拟最低佣金及所有交易所费用。
- 同花顺 `time_preview` 涨幅序列先转换为相对价格再判断承接；样本不足 4 点时跳过候选；同题材允许龙头、二龙头同时入选，仍按股票去重并限制 top_n。
- 行情缺失时沿用最后有效估值或成本，摘要明确标记估值过期，并让任务报失败。

## 自动任务

- `s19-signal-push.yml`：08:45 计划启动，等到监控窗口扫描并通过 Server酱通知；需要仓库 Secret `SERVERCHAN_SENDKEY`。当天去重状态经 Actions Cache 保存，覆盖正常同日重跑。
- `s19-paper.yml`：09:05 计划启动，监控至 15:01，适配托管任务 6 小时上限；账户、成交、净值和摘要自动提交。无推送，也无真实下单。
- 实时空池最多重试 2 次；当天曾有非空池却持续返回空池时标记数据异常，不发送“无信号”，不沿用旧候选成交。健康标记随账户或推送去重状态保存；新一天重置。历史收盘审计不使用此实时保护。
- 任一轮扫描/推送失败会在任务结束时返回非零，同时继续后续扫描。模拟仓失败时也保存快照 artifact 并尝试提交已有状态。
- GitHub 定时任务可能延迟；已错过完整信号窗口的任务会失败。无法保证首次信号捕获或通知零重复（例如成功发送后进程立即中断、缓存被删除）。
- 年度 A/B 审计仅比较收盘题材信号，不算收益或盘中成交；使用交易日历，记录空池交易日，数据缺失时返回失败。

## 文件与验证

`src/s19_paper.py` 是选股及模拟执行核心。`state/account.json` 保存账户；`logs/trades.csv` 保存成交；`logs/equity.csv` 保存估值；`outputs/latest.md` 是摘要。行情源没有正式服务保证，盘口快照不能证明真实成交。

```bash
pip install -r requirements.txt
python -m unittest discover -s tests -v
```

回归测试使用构造行情，不访问市场、不推送消息、不改真实账户。推送格式测试 `replay_push_test.py` 会真的发送测试通知，只供手工运行。
